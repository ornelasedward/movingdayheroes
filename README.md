# Moving Day Heroes

Marketing site for **Moving Day Heroes** — a professional moving company.

Domain: [movingdayheroes.com](https://movingdayheroes.com)

## Stack

- Vite + React + TypeScript
- Tailwind CSS + shadcn/ui
- Supabase (quotes, inbox, SMS, invoicing)

## Setup

```bash
npm install
npm run dev
```

## Brand config

Edit `src/lib/site.ts` for phone, email, city, service area, and social links.

## Inspired by

Layout and service structure inspired by [BC Brothers Moving](https://www.bcbrothersmoving.com/).
